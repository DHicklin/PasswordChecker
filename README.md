# PasswordChecker
A new type of password checker that checks for qualifications of passwords. Each password will not be able to be used again after one use. That way, someone could see your password and not be able to get into your account. For example, your password could be 4 ascending 2 digit numbers with spaces inbetween followed by a space a 2 lowercase letters. For this password, you could do something like 42 57 78 97 kn but you would need a slightly different group of charachters next time that still fits your qualifications
